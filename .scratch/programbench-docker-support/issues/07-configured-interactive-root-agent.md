## What to build

Allow Interactive Root Agents to carry an optional Agent Execution Config so ProgramBench can create a configured Root whose ordinary bash actions and spawned Child Agents share the same default Action Environment Binding.

## Acceptance criteria

- [x] Interactive Root workflow input can include an optional Agent Execution Config.
- [x] Unconfigured CLI Interactive Root behavior remains unchanged.
- [x] Configured Root ordinary bash uses its default Action Environment Binding.
- [x] Configured Root creation validates config shape and Action Environment Binding shape.
- [x] Configured Root creation does not preflight model provider credentials.
- [x] Configured Root Spawn uses the Root Agent Execution Config as the Child base config.
- [x] Child Spawn inherits Action Environment Bindings from the configured Root.
- [x] Child Spawn may override model or Agent behavior settings where existing spawn override semantics allow it.
- [x] Child Spawn may not override inherited Action Environment Bindings.
