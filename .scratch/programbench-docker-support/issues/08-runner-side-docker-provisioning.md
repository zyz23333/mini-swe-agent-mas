## What to build

Add a runner-side Docker provisioning utility that creates, verifies, and cleans up the already-provisioned Docker container expected by MAS `docker/shared` Action Environment Bindings.

## Acceptance criteria

- [x] The provisioner derives the same deterministic container name used by the Docker binding resolver.
- [x] The provisioner applies MAS diagnostic labels for workspace/runtime namespace, Root Agent ID when available, Action Environment ID, and binding kind.
- [x] The provisioner creates ProgramBench containers with `--network none`.
- [x] User-supplied Docker run arguments that request a different network mode are rejected for ProgramBench inference.
- [x] The provisioner verifies the container network mode with Docker inspect before MAS execution.
- [x] The provisioner verifies the created container is running.
- [x] Cleanup removes the provisioned container.
- [x] Default tests do not pull official ProgramBench images.
