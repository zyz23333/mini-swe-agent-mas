## What to build

Implement the `docker/shared` ordinary bash execution path for already-provisioned Docker containers, preserving MAS command interception and host-side model execution.

## Acceptance criteria

- [x] The executor resolves Docker containers by deterministic container name derived from workspace/runtime namespace and Action Environment ID.
- [x] The executor verifies MAS Docker labels before executing bash.
- [x] The executor verifies the named container is running.
- [x] The executor never calls `docker run` or provisions missing containers.
- [x] Missing, stopped, or label-mismatched containers produce `execution_blocked`.
- [x] `docker/shared` `cwd` is treated as a container-internal path.
- [x] `docker/shared` `env` is passed to `docker exec` as action-time environment variables.
- [x] Ordinary bash actions acquire the Action Environment Lock before `docker exec`.
- [x] Standalone `mini-mas ...` commands are still intercepted in-process and are not sent to Docker.
- [x] Default tests use mocked Docker or a tiny local fixture, not official ProgramBench images.
