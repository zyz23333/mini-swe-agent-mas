## What to build

## Acceptance criteria

- [x] Export reads from the `docker/shared` binding's container-internal `cwd`.
- [x] The generated archive is written to `<run-dir>/<instance_id>/submission.tar.gz`.
- [x] The archive root layout matches ProgramBench evaluation expectations.
- [x] Export excludes `.mini-mas/`, `.git/`, `__pycache__/`, `.pytest_cache/`, `.mypy_cache/`, `.ruff_cache/`, `.cache/`, nested `node_modules/.cache/`, and `.DS_Store`.
- [x] Export does not broadly exclude `build/`, `dist/`, or `target/`.
- [x] Export preserves executable bits and useful file metadata.
- [x] Tests use local fixtures and tar inspection.
